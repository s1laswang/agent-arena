Canary is a Bayesian insider-threat RL benchmark where an AI security lead plants canary traps to catch a mole before company value bleeds away. Across 80 verified gemini-4-carbon runs (6,359 API calls, $77.67 USD), Gemini powers six essential roles: leak-free world text, solvability-gated adaptive moles, 13-tool frontier investigators (paired v1.4 n=30: 87.5% of SolverPolicy, diff -0.0807 +/- 0.1453 95% CI), 1M-context failure analysis (100% verified quotes), whole-repo/MCP exploit hunting, and Part.from_bytes scan vision. ## 1. The Problem and Why It Matters

Organizations increasingly delegate high-stakes investigative workflows to AI agents: insider-threat triage, incident response, fraud review, and security operations. In each setting an agent must gather partial evidence under a tight daily action budget while company damage compounds, then commit to an irreversible accusation.

Conventional leaderboards compress evaluation into a single scalar score. That scalar cannot answer the three questions engineering teams need before deployment:
- **Where decisions break:** which specific action lost expected value relative to exact Bayesian reasoning (`premature_accusation`, `uninformative_canary`, `ignored_delay`, `over_restriction`, or `budget_waste`).
- **What extra thinking buys:** whether scaling inference-time reasoning (`thinking_level`) improves experimental design or commit timing, and at what token and dollar cost.
- **Whether the benchmark itself is fair and ungameable:** whether difficulty comes from genuine reasoning gaps rather than unsolvable worlds, leaked ground truth, or exploitable reward loopholes.

Canary automates the entire scientific loop on a single frontier model, `gemini-4-carbon`, pairing every episode against an exact Bayesian reference (`SolverPolicy`).

## 3. What Is Innovative and Technically Impressive

1. **Solvability-constrained adversarial co-evolution (`adaptive_mole`).** Rather than inflating difficulty through unfair noise, `gemini-4-carbon` evolves mole DSL strategies and proposes PAIRED scenarios rejected unless `SolverPolicy` stays high and `ObviousHeuristic` fails (`26` verified runs, `1,632` calls), including `results/gemini_roles/adaptive_mole/paired-skill-designer-carbon-hard` (commit `0e59cc10aa43f068e5fe7c1007215df1db4d10fe`, `kept 6/6 solvable scenarios, eval solver +0.628, heuristic -1.000, n=20`) and live head-to-head clashes such as `results/gemini_roles/adaptive_mole/carbon-vs-carbon-seed0` (commit `3bd1d1e2295aa320812f08e2eceaef5b4a8902ef`, `investigator +0.660 vs solver +0.400 (7d clash)`).
2. **Controlled `thinking_level` regret decomposition (`investigators`).** Holding `gemini-4-carbon`, the 13 tool definitions, and world seeds constant while toggling `thinking_level` (`low` vs `high`) separates information-gathering quality from stopping calibration: in `results/gemini_roles/investigators/thinking-ladder-carbon-hard0` (commit `3df4d2b65bd05a67f2d94ef18d967da05c0e90d7`), scaling from `0` to `52,968` thinking tokens eliminates `uninformative_canary` errors and slashes step-level solver regret from `0.1623` to `0.0298` (`81.6%` reduction) while exposing conservative commit delay.
3. **Checked-not-trusted long-context forensics (`failure_analyst`).** `gemini-4-carbon` reads full frontier trajectory corpora (`918,030` total input tokens across `3` runs) in single long-context calls, while every regret value comes from `canary.solver.regret` and every cited quote is verified character-for-character in Python (`100%` verified quotes).
4. **Whole-repo and live MCP red-teaming audited by server ledgers (`exploit_hunter`).** `gemini-4-carbon` plans and executes `11` audited role attacks (`8` in-process and `3` via live HTTP MCP, `655` tool calls) scored strictly from server-side ledgers, confirming `0` seed leaks across `12,000+` `public_world_match` probes.
5. **Causal pixel-only and multi-image multimodal ablations (`multimodal_evidence`).** Across `11` verified runs (`158` PNGs read via `Part.from_bytes`), Canary proves causal visual dependence: across `16` unique redacted-memo episodes (`80` scans), vision lifts score from `+0.2344` (blind) to `+0.6381` (`100.0%` oracle recovery), `results/gemini_roles/multimodal_evidence/access-heatmap-v14-sweep-carbon` (commit `b40e5c8ddd303039e7fb605ec50b4005a174a064`) separates moles from framed decoys (`90%` mole and `100%` decoy vs `0%` naive), and `results/gemini_roles/multimodal_evidence/carbon-trajectory-forensics` (commit `44b700f1b8d03f46eb90bc99142f4ffc221563cf`) hits `100%` threshold and exact-day chart forensics.

## 4. Why Gemini Is Essential

Removing `gemini-4-carbon` or its Gemini-native API controls from any of the six roles measurably degrades or disables Canary:

- **Explicit `thinking_level` control:** On `hard` seed `0` (`results/gemini_roles/investigators/thinking-ladder-carbon-hard0`, commit `3df4d2b65bd05a67f2d94ef18d967da05c0e90d7`), scaling from `0` (`low`) to `52,968` (`high`) thinking tokens cuts Bayesian step regret from `0.1623` to `0.0298` (`81.6%` reduction), while `results/gemini_roles/world_text/thinking-calibration-carbon` (commit `dbe9569fcc44abf8bc0665e0533dd1d1b677c6e9`) calibrates world-synthesis thinking tokens `0 -> 3,703 -> 38,674` across `low/medium/high`.
- **Thought signatures (`thought_signature`) across tool turns:** Preserving Gemini cryptographic `thought_signature` tokens across multi-turn 13-tool episodes (`3,333` investigator calls) keeps latent Bayesian hypothesis state intact across days and enables exact keyless trajectory replay (`scripts/verify_replay.py`).
- **Explicit and prefix context caching:** Serving **164,235,078** of **180,196,414** input tokens from explicit and prefix cache (**91.1%** cache hit rate across **6,359** calls and **80** runs) keeps the entire six-role benchmark suite at **$77.6700** (**$77.67 USD**) instead of roughly 4x list cost.
- **1M-token long context:** Ingests multi-episode trajectory corpora (`596,862` tokens across `101` episodes) and whole-repository whitebox security packs (`104` files, `203,463` tokens) in a single unfragmented pass, avoiding lossy RAG chunking while maintaining `100%` code-verified quotes.
- **Native multimodal vision (`Part.from_bytes`):** Ingests `158` rendered PNG scans, multi-image dossiers, SOC rasters, and trajectory charts via `Part.from_bytes(mime_type="image/png")`; removing vision on `16` unique redacted-memo episodes drops score from `+0.6381` to `+0.2344` (`100.0%` watermark accuracy, `100.0%` Bayesian text-oracle recovery), while naive log heuristics score `0%` on decoy-framed SOC rasters.
