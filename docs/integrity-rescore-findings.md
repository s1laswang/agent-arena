# Canary score recompute: findings

Test: `tests/test_integrity_rescore.py` (run `pytest tests/test_integrity_rescore.py -q -s`, offline). `canary_rescore(payload, mole=None, params=None)` recomputes V and the score from the /ledger payload only.

1. **Is the ledger enough?** Mostly. Leaks, canary plants, restrict/unrestrict days, the accusation, V at accusation and the end reason are all in it, so V = 1 - leak_damage x leaks - canary_cost x plants - restrict_cost x restricted days (clamped at 0) and score = V if correct, wrong_accusation_score if not, 0 without an accusation are recomputed exactly. Not enough: `correct` is only the server's claim. The payload has the tier but no seed and no mole, and judge worlds use a secret, so correctness can be checked only with the world (mole id), which only the server holds.
2. **Committed data.** 18 committed Harbor `verifier/ledger.json` files: 0 mismatches. 637 committed episodes (data/runs/committed, dev and held-out seeds) replayed through `Env` with the frozen tier version they were played under (v1.4, or v1.3 for old hard runs) and rescored with the true mole: 0 mismatches; 8 of them were recorded `error` and never ended (score 0, no accusation), 10 judge-seed episodes cannot be replayed (per-process secret).
3. **Fuzz.** 3 tiers x 12 seeds x up to 600 random tool calls (all tools, malformed-free args): served score == recomputed score and V in every run.
4. **Gap.** `harbor/template/tests/test.sh` writes `float(ledger["score"])` and never recomputes. A ledger with a forged score passes it as reward 1.0 (`test_harbor_test_sh_trusts_the_served_score_without_recompute`), while `canary_rescore` flags it. Today the ledger comes from the sidecar, so this needs a compromised sidecar, but a recompute in test.sh would make the verifier independent of the score code. Suggested: ship `canary_rescore` (without the mole check) into the verifier image and fail closed on any problem.
5. **Grader exceptions.** A tool exception inside `env.call` is caught by `Episode.call` and returns INTERNAL_ERROR; the episode stays open at score 0 until an accusation. An exception inside `score()` makes `ledger_payload` raise, so /ledger fails and test.sh fails closed (reward 0). test.sh also fails closed on malformed JSON, missing score, out-of-range, NaN and non-numeric scores (tests above).
