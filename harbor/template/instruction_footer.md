How to reach your tools:
- All your tools are on the MCP server named `pinbox`. It is already connected for you
  (streamable HTTP at `@@MCP_URL@@`).
- In OpenCode the tools are named `pinbox_<tool>`, for example `@@EXAMPLE_TOOL@@`.
- The task exists only behind these tools. Nothing in this container is part of it, and nothing
  you write in files or in your reply changes the result. Only what you do through the tools counts.
- The `get_task` tool gives you this task text again if you need it.
