# v1.4 eval charts (from PR #46)

Two charts brought from `origin/fr8/canary/eval` (commit 988e6daf, generated there by `scripts/build_eval_charts_v14.py`, which is not merged here). The frontier and solver numbers they show come from the committed episodes in `data/runs/committed/v1.4/`. The table of record is [`data/runs/committed/v1.4/paired_table_gemini.md`](../../data/runs/committed/v1.4/paired_table_gemini.md).

- [`headline_gap_paired_v14.png`](headline_gap_paired_v14.png): every v1.4 run as % of the solver on the same seeds 0–29, raw and luck-adjusted, with 95% paired bootstrap CIs. The frontier rows match the paired table: OpenCode gemini-4-carbon hard 65% [24%, 98%] raw, 72% [52%, 91%] luck-adjusted; OpenCode gemini-3.5-flash hard 75% [36%, 123%] raw, 22% [−23%, 63%] luck-adjusted; in-process gemini-4-carbon hard 95% [62%, 140%] / 84% [65%, 106%]; medium OpenCode 111% [99%, 127%] / 101% [85%, 119%]. **Caveat:** the `grok_tactics` and `heuristic` rows are n=30 deterministic replays computed on the PR #46 branch, not the n=20 baseline rows of the paired table (for example, hard heuristic is 17% here vs 40% [−12%, 108%] at n=20 in the table).
- [`posterior_calibration_v14.png`](posterior_calibration_v14.png): panel A plots each hard accusation's solver posterior P(accused) against the true V at that moment, with the break-even line P = 1/(1+V). The three below-break-even OpenCode gemini-4-carbon accusations (seeds 5, 18, 23) are the ones in [`docs/reports/failure_gallery_breakeven.md`](../../docs/reports/failure_gallery_breakeven.md). Panel B shows cumulative raw score vs luck-adjusted EV per cohort.

**Sensitivity, already in the paired table:** if OpenCode attempts that ended on an empty model reply are scored 0 instead of retried, OpenCode gemini-4-carbon hard is 56% [19%, 87%] of the solver (luck-adjusted 55% [34%, 77%]); the "alternative" rows of `paired_table_gemini.md` and README "Infra retries, disclosed".
