# FR8 Linux Docker Harbor 3x10 judge rehearsal

Completed 3x10 Docker Harbor judge rehearsal executed on the FR8 Linux host prior to final submission packaging. This directory (`results/harbor/rehearsal-fr8/`) is kept separate from `results/harbor/rehearsal/`, which is reserved for the macOS colima run.

- **Code (`BUILD.txt`):** commit `8cd20d9e0f92d88588b8a99f4d1aaa2260693f7e` (`8cd20d9e`), built `2026-11-14T23:18:51Z` with `agent_timeout_sec = 10800.0`.

- **Scheduling:** reference/probe jobs (`oracle`, `do_nothing`, `stop_early`, `cheat_probe`) ran at `-n 4` with `max_retries = 0`. The three `google/gemini-4-carbon` OpenCode jobs (`opencode-1`, `opencode-2`, `opencode-3`) ran concurrently at `-n 2` each (up to 6 containers in flight) with `--agent-setup-timeout-multiplier 4` and `--max-retries 2` on `AgentSetupTimeoutError` and `ApiRateLimitError` under a shared 2M input-tokens/min Gemini quota bucket shared with concurrent fleet runs.
